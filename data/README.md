# LUAD Data Directory

This directory contains the raw source data and processed datasets used in the LUAD mutation-centred sequence experiments.

## Raw Data

Path: data/raw/

### cBioPortal
Contains mutation, clinical-patient, and clinical-sample files from seven LUAD cohorts.

### IntOGen
Contains cancer driver-gene resources used for LUAD driver-gene selection and validation.

### Ensembl
Contains the selected CDS reference sequences for the 96-gene LUAD panel.

## Processed Data

### 101-bp
Path: data/processed/101bp/

Contains intermediate and final datasets used by the 101-bp mutation-centred sequence pipeline.

### 301-bp
Path: data/processed/301bp/

Contains the final mutation-level and patient-level datasets generated by the 301-bp pipeline.

## Git LFS

Large files in this directory are stored using Git LFS.
After cloning the repository, run:

git lfs install
git lfs pull

## Note

Raw source files are shared between the 101-bp and 301-bp experiments to avoid unnecessary duplication.
