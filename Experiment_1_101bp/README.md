# Experiment 1: 101-bp Mutation-Centred Window

This folder contains the first LUAD sequence-window experiment using 101-bp mutation-centred DNA sequences.

Each sequence window contains 50 bases upstream of the mutation site, the centred mutation position, and 50 bases downstream. The mutation position is represented at index 50.

This experiment serves as the baseline for comparison with the later 301-bp mutation-centred window experiment.
