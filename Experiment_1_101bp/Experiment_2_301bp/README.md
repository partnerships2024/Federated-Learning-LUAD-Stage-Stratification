# Experiment 2: 301-bp Mutation-Centred Window

This folder contains the main LUAD sequence-window experiment using 301-bp mutation-centred DNA sequences.

Each sequence window contains 150 bases upstream of the mutation site, the centred mutation position, and 150 bases downstream. The mutation position is represented at index 150.

This experiment extends the earlier 101-bp baseline by providing wider sequence context around each mutation and serves as the primary experiment in this study.
